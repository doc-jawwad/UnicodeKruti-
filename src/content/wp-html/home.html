Mini FAQ

What is the difference between Mangal and KrutiDev?

Mangal is a Unicode font. It stores Hindi as universal Unicode code points that work on any device without font installation. KrutiDev is a non-Unicode font. It stores Hindi as remapped ASCII characters that only display correctly when the font is active on the device. This tool converts Mangal to KrutiDev in one click.

Does it matter which Unicode font I used — Mangal, Kokila, or Nirmala UI?

No. All three are Unicode fonts and use identical Devanagari code points. The converter produces the same KrutiDev output regardless of which Unicode font the source text was typed in.

Common Unicode to KrutiDev Conversion Errors and Fixes

Most failed conversions are font problems after paste, not mapping errors — install Kruti Dev 010 and apply it to the pasted text. The cases below cover the rest.

Error 1: Output Shows Random English Letters

Cause: The Kruti Dev 010 font is not installed on the reading device. Fix: Download the font from our KrutiDev Font Download page. Install it. Open your document in MS Word. Select the pasted text. Change the font to Kruti Dev 010.

Error 2: Half-Characters or Conjuncts Look Wrong After Conversion

Cause: Some conjuncts use ZWJ (Zero Width Joiner, U+200D) instead of the standard halant (U+094D). ZWJ-based conjuncts do not map cleanly to KrutiDev ASCII. Fix: Remove ZWJ characters from the input text and reconvert. Standard halant-based conjuncts convert correctly.

Error 3: Text Looks Correct in Output Box but Wrong in MS Word

Cause: The text was pasted into Word but the font is still set to Calibri or Mangal. Fix: Select all pasted text. Open the font box in the Home ribbon. Type Kruti Dev 010 and press Enter.

Error 4: Scanned PDF Text Does Not Convert

Cause: Scanned PDFs contain images of text, not actual characters. This converter processes text data, not image pixels. Fix: Run the scanned PDF through an OCR tool first. Paste the extracted Unicode text here.

What Is KrutiDev?

KrutiDev is India's most widely used legacy Hindi font encoding. It is not Unicode. It stores Hindi as remapped ASCII characters that only display as Hindi when the KrutiDev font file is installed. Without the font, every character shows as a random English letter.

KrutiDev remains in active use because state government systems, court record software, and exam evaluation platforms were built on it. Migration across hundreds of district offices will take many years.
