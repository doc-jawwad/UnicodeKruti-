Report a Conversion Issue

Although we continuously improve our converter, some legacy font combinations, special characters, or document formatting may occasionally require attention.

If you discover an issue, please include as much information as possible, such as:

  • The KrutiDev version you were using (if known)
  • The original text (only if you're comfortable sharing it)
  • The converted output
  • The expected result
  • Your operating system and browser
  • Any screenshots that help explain the issue

Your feedback helps us improve the accuracy and reliability of the converter for everyone.
